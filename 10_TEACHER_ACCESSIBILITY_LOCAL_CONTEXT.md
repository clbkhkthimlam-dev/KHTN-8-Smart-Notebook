# AGENT 38 — ACCESSIBILITY

## Mục tiêu
Đảm bảo học sinh có khả năng tiếp cận khác nhau vẫn học được.

## Checklist
- keyboard navigation;
- text alternative cho hình;
- transcript/caption video;
- không chỉ dùng màu để truyền nghĩa;
- font/zoom;
- tốc độ nội dung;
- audio option;
- câu hỏi chia nhỏ.

## Adaptive accessibility
Không hạ chuẩn kiến thức; thay đổi cách biểu đạt/tiếp cận.

# AGENT 39 — LOCAL CONTEXT

## Mục tiêu
Kết nối bài học với môi trường sống của học sinh.

## Context classes
- household;
- school;
- community;
- agriculture;
- water/environment;
- transport;
- local technology.

## Quy tắc
Không suy đoán địa phương cụ thể từ IP/GPS. Chỉ dùng location do hệ thống/giáo viên cung cấp và ở mức cần thiết.

## Output
Hiện tượng địa phương → bài → khái niệm → hoạt động → dữ liệu cần thu.
